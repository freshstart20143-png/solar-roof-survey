# 光電屋頂探勘

在空拍圖上劃出屋頂，估算可以裝多少太陽能板、一年發多少電、賣多少錢。
適用全台 17 縣市（不含澎湖、金門、馬祖）的透天厝。資料只存在自己的手機，不會上傳。

## 下載安裝（安卓手機）

👉 **[下載最新版 APK](https://github.com/freshstart20143-png/solar-roof-survey/releases/latest/download/solar-roof-survey.apk)**

1. 用手機點上面的連結，下載 `solar-roof-survey.apk`
2. 下載完點開檔案。第一次會跳出「不允許安裝不明來源的 App」，按「設定」→ 打開「允許這個來源」→ 返回
3. 按「安裝」
4. 桌面會出現青綠色的「光電屋頂探勘」

之後有新版本，一樣點上面的連結下載安裝，會直接蓋過舊版，劃過的屋頂都還在。

## 怎麼用

1. 打開後，用右上角的定位按鈕跳到目前位置，或手指拖動、兩指縮放找到房子
2. 放大到看得清楚屋頂，按下方「**劃屋頂**」
3. 依序點屋頂的每個角（L 型屋頂就多點幾個角），點錯可以拖動藍點或按「復原一點」
4. 按「完成」，就會看到可裝容量、每年售電等估算
5. 縣市會依屋頂位置自動選好（可以用下拉選單改），填上地址，按「查地籍樓層」會複製地址並打開地籍網站，在「門牌地址定位」貼上，就能看到登記樓層，回來填上
6. 「屋頂清單」可以看全部劃過的屋頂

## 計算方式

- 片數 ＝ 屋頂面積 × 65% ÷ 每片面積（1.879 m × 1.045 m）
- 容量 ＝ 片數 × 445W
- 第一年發電 ＝ 容量 × 縣市日照時數（2025 年氣象署）× 365，之後每年衰退 0.6%
- 售電 ＝ 發電度數 × 115 年屋頂型躉購費率（依容量級距；苗栗以北、台中以南、台東三組，依縣市自動套用）
- 符合條件：屋頂至少 14 坪、容量至少 7 kW（右上角齒輪可以調整）

## 注意

- **沒有判斷遮蔭**，被旁邊大樓或樹擋到的屋頂也可能顯示「符合」，請自己看空拍確認
- 屋頂有大型樓梯間、水塔、斜屋頂時，估出來的片數會偏多
- 數字僅供篩選參考，報價前請現場確認
- 資料存在各自手機，換手機或清除 App 資料會不見
